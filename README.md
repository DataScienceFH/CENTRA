# CENTRA Feedback Repository

This repository contains **no application code**.  
Its sole purpose is to provide a central place for:

- Reporting bugs or issues encountered in the CENTRA browser  
- Suggesting new features or improvements  
- Sharing ideas, comments, or general feedback  

If you want to contribute feedback, simply click the logo above or open an issue in this repository.

---

## What is CENTRA?

CENTRA is a Shiny-based browser application that enables exploration of topic-specific biological knowledge networks derived from literature associated with MSigDB C2 gene sets.  
It allows users to:

- Inspect topic-level network structure  
- Explore module functions  
- View gene-level metrics  
- Generate hypotheses about functional relevance and regulatory roles  

More information is available on the project website:  
**https://ngs-info.medizin.uni-halle.de/shiny/CENTRA**
